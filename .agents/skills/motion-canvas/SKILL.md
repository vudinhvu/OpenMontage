# Motion Canvas for OpenMontage

Use only when the approved `render_runtime` is `motion-canvas`.

1. Read `skills/core/motion-canvas.md` and the selected pipeline's compose director before authoring.
2. Keep generator scenes in the project workspace and tie each scene to a scene-plan ID.
3. Bring in diagram assets from `asset_manifest`; do not replace source diagrams with screenshots.
4. Use approved playbook and brand inputs; missing tokens remain unverified.
5. If dependencies or rendering fail, return the blocker. Never swap to another runtime without an approved proposal decision.
